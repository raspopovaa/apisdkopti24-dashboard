# Пульт топливных карт — описание прототипа

Документ фиксирует согласованный прототип дашборда (версия от 11.10.2026): назначение,
данные, архитектуру, оформление и поведение каждого блока. Это входные данные для
спецификации и разработки рабочей версии.

- Прототип: `prototype/dashboard.html` (одна страница) и `prototype/russia-regions.json`
  (границы регионов). Опубликован как приватный артефакт Claude «Пульт топливных карт».
- Подготовка карты: `scripts/build_regions_geo.py`.
- План и журнал решений: заметка «Дашборд MVP — план» в Obsidian
  (`Разарботка/apisdkopti24-examples`).

## 1. Общее описание

Одностраничный веб-дашборд по договору топливных карт ОПТИ 24. Данные получает сервер
через SDK `apisdkopti24`; браузер видит только готовые снимки с сервера. Пример для
портала примеров SDK.

Что показывает:

1. Шапка: договор (с выбором из нескольких), месяц, состояние обновления и три
   показателя договора — баланс, последний платёж, расход за месяц.
2. Скидки: скидка, сервисный сбор, процент скидки, итоговая цена литра, график итоговой
   цены по дням с фильтрами.
3. Группы карт (только если у договора есть группы): литры, заправки, стоимость, виды
   топлива, средняя скидка и цена литра по группам; статистика группы по клику.
4. Последние 10 транзакций с подробностями по клику и выгрузкой транзакционного отчёта
   за месяц в Excel или CSV.
5. География заправок: карта регионов России с точками АЗС и карточкой АЗС.
6. Аналитика: расход по дням, структура по продуктам, цена литра, топ-5 карт, контроль,
   тепловая карта заправок, запросы к API.

Режим прототипа — DEMO-стенд. Показатели договора — реальные ответы DEMO
`get_contract_data`; транзакции на DEMO непригодны (HTTP 405, чужие карты), поэтому журнал
и аналитика построены на синтетике, откалиброванной по литрам и рублям договора. Синтетика
помечена значком «пример данных».

## 3. Стиль

### 3.1. Общий характер

Светлая тема, синяя гамма с голубыми градиентами, «стеклянные» карточки в шапке, мягкие
тени, скруглённые углы. Есть тёмная тема (автоматически по настройке системы или по
атрибуту `data-theme`), с теми же ролями цветов. Все анимации отключаются при системной
настройке «уменьшить движение» (`prefers-reduced-motion`).

## 4. Архитектура

### 4.1. Поток данных

```text
API ОПТИ 24 ── SDK apisdkopti24 (1 запрос/с) ── сервер (FastAPI, один процесс)
                                                 │ фоновое обновление по расписанию
                                                 │ база: история 3 месяца
                                                 ▼
                       браузер ── GET снимков блоков (раз в 10 с, ETag) ── дашборд
```

- Ключи API, логин и пароль — только на сервере; в браузер не попадают.
- Сервер опрашивает API по своему расписанию, независимо от числа зрителей.
- При подключении договора база заполняется за 3 месяца: транзакционный отчёт
  `tsc_report_transaction_reriod` по месяцам (3 заказа + 3 скачивания), `get_payments`,
  справочники. Дальше — суточный отчёт и `get_transactions_v2` внутри дня.
- API сервера (план): `GET /api/contracts`, `GET /api/contracts/{key}/blocks/{block}?month=YYYY-MM`,
  `GET /api/contracts/{key}/version` (ETag). В адресах — только непрозрачный ключ договора.

### 4.2. Устройство страницы

- **Блоки-компоненты.** Каждый блок — функция отрисовки за выбранный месяц
  (реестр `BLOCKS`): расход, скидки, группы карт, журнал, карта, расход по дням, структура, цена литра,
  топ карт, контроль, тепловая карта.
- **Только видимые блоки.** `IntersectionObserver` (запас 200 px): блок на экране
  рисуется и обновляется, остальные помечаются устаревшими и обновляются при прокрутке.
  Графики создаются при первом показе блока.
- **Опрос раз в 10 с** проверяет версию снимка; без изменений ничего не перерисовывается.
  В скрытой вкладке опрос останавливается, при возврате — сразу опрос.
- **Важно.** Видимость блоков экономит браузер и сервер, но не запросы к API ОПТИ 24.
  Запросы к API экономятся расписанием сервера, инкрементальной загрузкой и суточным отчётом.

### 4.3. Структура страницы

```text
┌ Шапка (градиент) ───────────────────────────────────────────────┐
│ Пульт топливных карт · [Договор ДМ-000101 ▾] [Октябрь 2026 ▾]   │
│                         DEMO · ● обновлено 12:00:10 · ◔ 10 с    │
│ [Баланс договора]  [Последний платёж]  [Израсходовано в октябре]│
└─────────────────────────────────────────────────────────────────┘
┌ Скидки: 4 показателя · фильтры · итоговая цена литра по дням ───┐
┌ Группы карт (если есть): таблица групп · фильтры ───────────────┐
┌ Последние 10 транзакций ────────────────────────────────────────┐
┌ География заправок: карта (2/3) · легенда и рейтинг (1/3) ──────┐
┌ Расход по дням (2/3) ─────────┐┌ Структура по продуктам (1/3) ──┐
┌ Цена литра ┐┌ Топ-5 карт ┐┌ Контроль ┐
┌ Когда заправляются (2/3) ─────┐┌ Запросы к API (1/3) ───────────┐
└ Подвал: источники данных ───────────────────────────────────────┘
```

На ширине до 1000 px все блоки — в одну колонку; на телефоне — поля 16 px, таблицы
прокручиваются внутри своих блоков.

## 5. Глобальные элементы и фильтры

### 5.1. Выбор договора

- Кнопка в шапке: «Договор» + полный номер (`auth_user` → `contracts[].number`) + стрелка.
- Всплывающее меню: заголовок «Договоры учётной записи · N», строка — точка состояния
  (синяя — норма, красная — баланс ниже нуля, серая — нет расхода), номер, баланс,
  подпись («27 455 л в этом месяце», «баланс ниже нуля», «нет расхода в этом месяце»).
- Клавиатура: ↑ ↓ Home End, Enter/пробел — выбор, Esc — закрыть. Клик мимо — закрыть.
- Действие: загрузка ~0,65 с (бегущий блик, числа полупрозрачные) → перерисовка шапки
  и всех видимых блоков; числа плавно переходят к новым значениям; выбор запоминается
  в браузере (`localStorage`). При одном договоре меню нет.

### 5.2. Месяц

- Одно поле рядом с номером договора: текущий месяц («Октябрь 2026 · текущий») и два
  прошлых. Прошлый месяц подсвечивается (поле светлее, рамка белая).
- Действие: все блоки переходят на выбранный месяц (видимые — сразу, остальные — при
  прокрутке); закрывается открытый график за 3 месяца. Баланс и последний платёж от
  месяца не зависят.

### 5.3. Состояние обновления

Пилюли «DEMO», «● обновлено ЧЧ:ММ:СС» и «◔ следующее через N с» (кольцо отсчёта).
Раз в 10 с — опрос версии; блик по шапке и пульс точки.

### 5.4. График за 3 месяца

- Открывается кликом (Enter или пробел) по значению показателя; закрывается повторным
  кликом, кликом мимо, Esc или прокруткой. Подсказок при наведении нет.
- Окно 250 px: заголовок «<показатель> · 3 месяца», три столбца (градиент синего; выбранный
  месяц ярче), значения над столбцами, месяцы под ними, пояснение источника.
- Открытый показатель подчёркнут; при наведении показатель слегка подсвечен.
- Есть у: последнего платежа, расхода ₽ и л, четырёх показателей «Скидок» (с учётом
  фильтров), цены литра по каждому виду топлива. Нет у баланса и у счётчиков «Контроля».

## 6. Блоки

### 6.1. Шапка: показатели договора

Три стеклянные плитки на градиенте (фон `rgba(255,255,255,.14)`, размытие 14 px,
рамка `rgba(255,255,255,.28)`), белый текст.

| Плитка | Содержимое | Данные | Действия |
|---|---|---|---|
| Баланс договора | только текущий баланс выбранного договора, крупно по центру | `get_contract_data` → `balanceData.balance` | нет (решение 18) |
| Последний платёж | сумма, дата «Поступил ДД.ММ.ГГГГ», источник | `balanceData.last_payment_sum`, `last_payment_date` | клик по сумме — платежи за 3 месяца (`get_payments`) |
| Израсходовано в <месяце> | рубли и литры; «X % от объёма <прошлого месяца> (N л) +Y %»; полоса доли (градиент `#bae6fd → #fff`); источник | текущий месяц — `consumption_for_month`, `_volume`; прошлые — сумма транзакций из базы | клик по ₽ или л — 3 месяца |

### 6.2. Скидки

- **Назначение:** сколько договор получил скидки и отдал сбора и во что обошёлся литр.
- **Показатели** (4 плитки в ряд, на планшете 2×2):
  1. Сумма скидки за месяц — синий текст. Формула: Σ скидки − Σ наценки.
  2. Сервисный сбор за месяц, с подписью ставки («3,75 % суммы»).
  3. Процент скидки к цене АЗС = Σ скидки / Σ суммы без скидки × 100; отрицательный — красный.
  4. Средняя цена литра со скидкой и сбором = (Σ суммы + Σ сбора) / Σ литров; рядом цена
     на стеле; плитка с голубым градиентом, число градиентным текстом.
- **Фильтры** (в одну строку): «Вид топлива» (по умолчанию основное, «— основное» в
  списке), «Тип АЗС», «Регион АЗС», «Сбросить фильтры» (видна, если фильтры отличаются от
  умолчания). Активный фильтр — голубой фон. Подпись над блоком: «ДТ (основное топливо) ·
  Газпромнефть».
- **График:** итоговая цена литра по дням месяца — синяя линия 2,5 px с заливкой и
  подписью последнего значения; цена на стеле — серый пунктир; ось ₽, легенда сверху.
- **Действия:** смена фильтра → пересчёт показателей и графика; клик по показателю — 3 месяца.
- **Данные:** только топливо; отчёт: `F_DISCOUNT`, `F_SERVICE_FEE`, `F_SUM`,
  `F_SUM_WO_DISCOUNT`, `F_QTY`, `S_OWN_TYPE`, `S_REGION`.

### 6.3. Группы карт

- **Показ:** блок есть, только если у договора есть группы карт (`get_card_groups`);
  у договора без групп скрыт, при смене договора показывается или скрывается сразу.
- **Таблица** (строка на группу, «Без группы» — всегда последней, если есть карты без
  группы):
  - Группа: название, «N из M карт заправлялись», полоса объёма (градиент синего, ширина —
    доля от самой крупной группы).
  - Литры, заправок.
  - Стоимость, ₽: сумма по договору со скидкой; со сбором — в подсказке.
  - Виды топлива: до четырёх видов с цветной точкой Goods и долей в литрах.
  - Средняя скидка: Σ скидки / Σ суммы без скидки, синяя «−» / красная «+».
  - Цена литра по договору (без фильтра топлива — среднее по видам, это подписано).
  - Строка «Итого по договору» внизу (серый фон).
- **Фильтры:** «Все группы · N» / группа, «Все виды топлива» / вид; активный — голубой фон;
  подпись над таблицей: «Колонна 1 · ДТ».
- **Анимация:** строки въезжают слева, как в журнале; полосы объёма растут (1 с).
- **Действие: клик / Enter / пробел по строке → окно группы** (за выбранный месяц, всё
  топливо):
  - Реализация группы: литры и тонны, сумма, скидка или наценка, сбор, итоговая цена литра,
    заправок и средний объём, доля в объёме договора, час пик, последняя заправка (местное,
    МСК, АЗС).
  - Виды топлива: цена на стеле, по договору, скидка %, со сбором, литры, заправок.
  - АЗС (до 8): номер, тип, адрес, литры, заправок, скидка.
  - Карты группы (все, включая не заправлявшиеся): номер, комментарий, заправок, литры,
    сумма, последняя заправка (МСК).
- **Данные:** группы — `get_card_groups` (id, название, cards_count); принадлежность карты —
  `get_cards_v2` (`group_id`, `group_name`) или отчёт (`ID_CARD_GROUP`, `S_GROUP_NAME`); всё
  бесплатно. В прототипе группы условные: у ДМ-000101 — «Колонна 1», «Колонна 2», «Доставка»,
  «Сервис и торговые»; у ДМ-000102 — «Колонна 1», «Доставка»; у ДМ-000103/104 групп нет.

### 6.4. Последние 10 транзакций

- **Выгрузка отчёта:** кнопка «⤓ Выгрузить отчёт» (градиент синего) в шапке блока → меню
  «Отчёт · <месяц> · N транзакций»: **Excel** (.xlsx) или **CSV** (.csv). В файл попадают
  все транзакции выбранного месяца, не только последние 10, по времени транзакции.
  - Колонки (23): местное время АЗС, часовой пояс, время МСК, номер транзакции, тип операции,
    карта, комментарий карты, группа карт, АЗС, тип АЗС, регион, адрес, продукт, код Goods,
    литры, масса (кг), цена на стеле, цена по договору, сумма без скидки, скидка (−) /
    наценка (+), сумма по договору, сервисный сбор, списано со счёта.
  - Excel: лист «Транзакции», заголовок отчёта (договор, месяц, время формирования), даты и
    числа — значениями с форматами, автофильтр, закреплённая шапка, строка «Итого».
    Библиотека SheetJS загружается при первой выгрузке.
  - CSV: UTF-8 с BOM, разделитель «;», десятичная запятая — для русского Excel.
  - Имя файла: `opti24_transactions_DM-000101_2026-10.xlsx` (номер договора латиницей).
  - Сохранение: в просмотрщике Claude — возможность `downloads` (пользователь подтверждает);
    вне его — обычное скачивание. Статус рядом с кнопкой: «Готовлю Excel…», «Сохранён …»,
    «Сохранение отменено».
  - В рабочей версии файл формирует сервер из базы
    (`GET /api/contracts/{key}/report?month=YYYY-MM&format=xlsx|csv`), без запросов к API.

- **Колонки:** местное время АЗС (`ДД.ММ.ГГГГ, ЧЧ:ММ` + пояс `UTC+7`), время МСК, карта
  (••последние 4 цифры с иконкой карты), АЗС (номер, метка типа «сеть»/«франчайзинг»/
  «партнёр», адрес), продукт (цветная точка Goods + название), литры, цена, сумма,
  скидка (синяя «−» / красная «+» / серая «0,00»), сбор, отметки.
- **Отметки:** «↺ сторно» (сумма зачёркнута), «☾ ночью» (00–05), «▲ объём» (больше порога
  контроля), «наценка», «без скидки».
- **Порядок:** по моменту транзакции (UTC), не по местным часам.
- **Действие:** клик / Enter / пробел по строке → окно транзакции:
  - Покупка: продукт и код Goods, литры, цена на стеле, цена по договору, скидка или
    наценка (₽, ₽/л, %), сумма, сервисный сбор со ставкой, списано со счёта договора,
    итоговая цена литра.
  - АЗС: номер и тип, адрес, регион.
  - Карта и время: карта и комментарий, местное время с поясом, МСК, UTC, способ оплаты.
  - Источник: `get_transaction_detail` (бесплатно), тип АЗС и сбор — из отчёта.

### 6.5. География заправок

- **Карта регионов:** Natural Earth 1:10m (общественное достояние), `adm0_a3 = RUS`,
  84 региона (Ненецкий АО объединён с Архангельской областью — как в справочнике `Region`).
  Проекция — коническая Ламберта (центральный меридиан 100°, параллели 50° и 70°), Чукотка
  цельная. Масштаб по умолчанию 1,3, до ×400; перетаскивание левой кнопкой, колесо.
- **Показатель заливки** (переключатель): тонны (корневая шкала от нуля), цена литра,
  скидка (синий — скидка, красный — наценка, серый — около нуля). Регионы без заправок —
  серо-голубые с белыми границами. Подсветка региона при наведении — голубая.
- **Вид топлива на карте:** список, по умолчанию основное.
- **Точки АЗС:** по координатам `F_LATITUDE`/`F_LONGITUDE`; размер — литры договора на
  АЗС; синий кружок с белой обводкой; подпись «№412» (перекрытые подписи скрываются).
- **Группы:** АЗС ближе 26 px — голубой кружок с числом; клик приближает в 3 раза к его
  станциям; группы пересчитываются после окончания движения карты (180 мс).
- **Кнопки:** «+», «−», «⤢ вся страна». Масштаб и центр сохраняются при смене месяца,
  топлива и показателя.
- **Справа:** легенда шкалы и рейтинг регионов (тонны, ₽/л, скидка). Наведение на строку
  подсвечивает регион и показывает подсказку.
- **Подсказка региона:** тонны и литры, цена по договору и на стеле, скидка, заправок.
- **Действие: клик по точке АЗС → карточка АЗС** (за выбранный месяц):
  - Реализация: литры и тонны, сумма, скидка или наценка, сбор, заправок и средний объём,
    доля в объёме договора, час пик, последняя заправка (местное и МСК).
  - Цены по видам топлива: на стеле (справочник АЗС, дата), по договору, разница %, со
    сбором, литры. Нет цен в справочнике — пометка.
  - Карты: номер, комментарий, заправок, литры, сумма, последняя заправка (МСК).
  - АЗС: тип, регион, координаты, часовой пояс.
- **Данные:** тонны = Σ `F_WEIGHT` / 1000 (в отчёте килограммы); без отчёта — литры ×
  плотность.

### 6.6. Расход по дням

- Столбцы по дням месяца, стопка по видам топлива цветами Goods, зазор 1 px, скругление
  верхнего сегмента 4 px; легенда сверху.
- Переключатель «₽ / литры» (в литрах — только топливо).
- Подсказка: дата, итог дня, доли видов топлива.

### 6.7. Структура по продуктам

- «Пончик»: радиусы 54–82 %, зазоры между секторами, скругление 5 px; в центре сумма за
  месяц («1,2 млн ₽ · за месяц»); проценты на секторах (меньше 5 % — только в легенде);
  цвет подписи по яркости сектора; легенда справа с процентами.
- Анимация — проявление с масштабом, 1 с.

### 6.8. Цена литра

Строка на вид топлива: название, средняя цена по договору (₽/л), разница к стеле —
«скидка −1,49» (синяя) или «наценка +…» (красная). Клик по цене — 3 месяца.

### 6.9. Топ-5 карт

Горизонтальные столбцы с градиентом синего на светлой подложке; слева номер карты
(••XXXX) и под ним комментарий карты (до 24 символов); справа сумма («38 тыс»).
Подсказка: номер, полный комментарий, сумма.

### 6.10. Контроль

- Две кнопки-счётчика: «▲ больше X л за раз» (оранжевая цифра) и «⟳ N заправки за H ч»
  (синяя цифра). Пороги — поля под ними (по умолчанию 80 л, 3 заправки, 4 ч).
- Действие: смена порога → пересчёт; клик по счётчику → окно со списком: карта и
  комментарий, местное время АЗС, АЗС (тип, адрес), продукт, литры, сумма. Частые
  заправки сгруппированы по событиям («Карта ••6946 · КамАЗ 5490 · 4 заправки за 2 ч
  33 мин · 202 л»). Клик по строке → окно транзакции.
- События ищутся по моменту транзакции (UTC).

### 6.11. Когда заправляются

Тепловая карта «день недели × час» по местному времени АЗС, синяя шкала, ячейки со
скруглением 4 px и зазором 2 px; проявление волной; подсказка: день, час, число заправок.

### 6.12. Запросы к API

- Запросов в этом месяце (DEMO: расчёт по расписанию), из них тарифицируемых («0 · DEMO»).
- Бесплатный пакет 500: «остаток N из 500» и полоса (красная при перерасходе).
- Прогноз для рабочей среды по расписанию и совет: при опросе договора и транзакций раз в
  час и суточном отчёте — 50 тарифицируемых в сутки, ~1 550 в месяц, пакет кончится
  ~11-го; уложиться — договор раз в 2 часа, транзакции из суточного отчёта (~434 в месяц).
- Расписание, лимит SDK 1 запрос/с, «Блоки на экране: видно N из 10 · ждут показа M».
- Факт — бесплатный `get_info` (на DEMO статистики нет). Размер пакета зависит от тарифа.

### 7.2. Правила и формулы

- **Скидка/наценка:** в отчёте `F_DISCOUNT = (F_PRICE_WO_DISCOUNT − F_PRICE) × F_QTY`,
  положительна при скидке. В интерфейсе скидка — «−», наценка — «+». Тип определяется по
  ценам: цена ниже цены на стеле — скидка, равна — без скидки, выше — наценка.
- **Сервисный сбор:** % от стоимости каждой покупки (с НДС), списывается сверх цены;
  ставка по объёму прошлого месяца: до 40 000 л — 3,75 %, 40 001–100 000 — 3 %,
  100 001–150 000 — 2,5 %, 150 001–500 000 — 1,5 %, больше — 1 % (оферта ред. 10.2026).
  Ставки — настройка с редакцией оферты, у договоров условия могут отличаться.
- **Время:** местное время АЗС — `DT_TRANS` (ISO со смещением) или `timestamp` API v2
  (местное время с ошибочным `Z`); общее — МСК из UTC (`utc_time`).
- **Тонны:** Σ `F_WEIGHT` / 1000.
- **Основное топливо:** вид с наибольшим числом литров за месяц.
- **Контроль:** объём больше порога за одну заправку; N заправок одной картой за H часов
  (окно по UTC, события не перекрываются).

### 7.3. Синтетика прототипа

Транзакции генерируются детерминированно по договору на 3 месяца, калибруются по литрам
(и по рублям, если средняя цена литра DEMO правдоподобна — 30–150 ₽). 14 АЗС: Новосибирская,
Томская, Кемеровская, Омская области, Алтайский и Красноярский края, Тюмень, Екатеринбург,
Челябинск, Москва. Скидка на собственных АЗС ~6,6 % (как в отчёте за апрель 2024),
франчайзинг — без скидки, партнёры — наценка 1–2,5 %. Номера договоров, адреса, координаты
и комментарии карт — условные.

## 9. Доступность и адаптивность

- Все интерактивные элементы доступны с клавиатуры; фокус виден (синяя обводка 2 px).
- Метки продукта дублируют цвет текстом; отметки — значком и словом.
- `aria-live` у статуса обновления, `aria-busy` при загрузке договора, роли `listbox`,

## 10. Что вне прототипа

Рабочий сервер (FastAPI, база, расписание, отчёты), авторизация для рабочих договоров
(полный номер договора — коммерческие данные; публичная страница — только DEMO),
развёртывание на VPS (Docker Compose, Caddy), портал MkDocs. Трассы с номерами — только из
OpenStreetMap, если понадобятся.
