# apisdkopti24-dashboard

Пульт топливных карт — пример использования асинхронного SDK
[apisdkopti24](https://pypi.org/project/apisdkopti24/) для API топливных карт ОПТИ 24.
Дашборд показывает, как из ответов API собрать картину по договору: деньги, расход,
скидки, географию заправок, поведение карт и нагрузку на тариф.

**Посмотреть:** [raspopovaa.github.io/apisdkopti24-dashboard](https://raspopovaa.github.io/apisdkopti24-dashboard/)

Проект в разработке. Опубликован прототип интерфейса. Сервер на FastAPI, который будет
обращаться к API через SDK, ещё не написан.

## Что показывает дашборд

| Блок | Что видно | Какой вопрос закрывает |
|---|---|---|
| Шапка | баланс, последний платёж, расход месяца в ₽ и литрах, сравнение с прошлым месяцем | хватит ли денег, растёт ли расход |
| Скидки | сумма скидки и сервисного сбора, средний % скидки, итоговая цена литра; фильтры по топливу, типу АЗС, региону; график цены по дням | сколько экономит договор и во что обходится литр с учётом сбора |
| Группы карт | литры, заправки, стоимость, виды топлива, средняя скидка и цена литра по группе | какие подразделения или колонны тратят больше и где дороже |
| Последние 10 транзакций | местное время АЗС и МСК, карта, АЗС и её тип, товар, литры, цена, скидка или наценка, отметки «ночью», «объём», «сторно» | что происходит прямо сейчас; выгрузка в Excel и CSV |
| География заправок | карта регионов РФ: тонны, цена литра или скидка; точки АЗС с карточкой | где заправляется парк, где топливо дороже и где теряется скидка |
| Расход по дням | столбцы по видам нефтепродуктов, ₽ или литры | ритм потребления, всплески и провалы |
| Структура по продуктам | доли АИ-92, АИ-95, АИ-98/100, ДТ, СУГ, товаров и услуг | на что уходят деньги |
| Цена литра | средняя цена и разница со стелой по каждому топливу | какое топливо покупается выгоднее |
| Топ-5 карт | самые расходные карты с комментариями | кто тратит больше всех |
| Контроль | крупные разовые заправки и частые заправки за короткое время | признаки слива и злоупотреблений |
| Когда заправляются | тепловая карта: день недели × час (время АЗС) | ночные и нетипичные заправки, график работы парка |
| Запросы к API | запросы за месяц, тарифицируемые, остаток пакета, прогноз | хватит ли пакета запросов при выбранном расписании |

Любой показатель шапки и блоков по клику открывает график за 3 месяца. Один переключатель
месяца управляет всем дашбордом.

## Какие методы SDK используются

Тарификация и доступность на DEMO указаны по `specifications/api-methods.yaml` из
репозитория SDK. Тарификацию нельзя определить по HTTP-методу или названию метода.

| Данные | Вызов SDK | Используемые поля и параметры | Тариф | DEMO |
|---|---|---|---|---|
| Договоры учётной записи | `client.auth.auth_user(contract_id=...)` | номера и ID договоров для меню | нет | есть |
| Баланс, платёж, расход месяца | `client.contracts.get_contract_data()` | `balanceData`: `balance`, `available_amount`, `last_payment_sum`, `last_payment_date`, `consumption_for_month` (₽), `consumption_for_month_volume` и `consumption_for_prev_month_volume` (л) | **да** | есть |
| Платежи за 3 месяца | `client.contracts.get_payments()` | суммы и даты платежей | **да** | есть |
| Транзакции за день | `client.transactions.get_transactions_v2(date_from=..., date_to=..., page_limit=..., page_offset=...)` | `utc_time`, `timestamp` (местное время АЗС), `card_id`, `poi_id`, `type`, `product_id`, `product_name` | **да** | есть, но без пригодных данных |
| Подробности транзакции | `client.transactions.get_transaction_detail(transaction_id=...)` | позиции транзакции для окна подробностей | нет | есть |
| История транзакций | `client.reports.order_report(report_id="tsc_report_transaction_reriod", format=..., params={"start_date": ..., "end_date": ..., "id_agreement": [...]})`, затем `get_report_jobs()` и `download_report_file(job_id=...)` | цены стелы и клиента, скидка, сервисный сбор, тип и регион АЗС, координаты, масса | **да**: заказ и скачивание | заказ есть, скачивания нет |
| Карты и группы | `client.cards.get_cards_v2(page=..., onpage=...)`, `client.card_groups.get_card_groups()` | комментарий карты, группа | нет | есть |
| Названия, коды и цвета топлива | `client.dictionaries.get_dictionary(name="Goods")` | `id`, `name`, `hex_color` | нет | есть |
| Регионы | `client.dictionaries.get_dictionary(name="Region")` | названия субъектов для карты | нет | есть |
| АЗС: координаты, тип, цены | `client.dictionaries.get_azs_list_v1(page=..., onpage=...)` | координаты, `ownType`, адрес, `prices` | нет | есть |
| Статистика запросов | `client.auth.get_info()` | запросы за период | нет | есть |

Ставки сервисного сбора и скидок берутся из приложения 1 к договору оферты, а не из API.

### Пример: показатели шапки

`get_contract_data` тарифицируется: один вызов — один запрос по тарифу. Повторы и повторная
аутентификация в SDK тоже расходуют запросы.

```python
import asyncio
from pathlib import Path

from apisdkopti24 import APIClient, ConnectionSettings, EnvironmentCredentialsProvider


async def main() -> None:
    env_file = Path(__file__).with_name(".env")
    settings = ConnectionSettings.from_env(env_file=env_file)
    credentials = EnvironmentCredentialsProvider.from_env(env_file=env_file)

    async with APIClient(settings=settings, credentials_provider=credentials) as client:
        await client.auth.auth_user(contract_id="contract-id")
        try:
            # Бесплатный справочник: названия и цвета топлива для графиков.
            goods = await client.dictionaries.get_dictionary(name="Goods")
            print("Товаров в справочнике:", goods.data.total_count if goods.data else 0)

            # Тарифицируемый вызов: баланс, последний платёж и расход месяца.
            contract = await client.contracts.get_contract_data()
            balance = contract.data.balanceData
            print("Баланс:", balance.balance, balance.currency)
            print("Последний платёж:", balance.last_payment_sum, balance.last_payment_date)
            print("Расход месяца, ₽:", balance.consumption_for_month)
            print("Расход месяца, л:", balance.consumption_for_month_volume)
        finally:
            await client.auth.logoff()


if __name__ == "__main__":
    asyncio.run(main())
```

## Какие инсайты можно получить

- **Реальная цена литра.** Цена со скидкой плюс сервисный сбор показывает, во что
  обходится литр на самом деле. Сбор платится сверх цены, а его ставка зависит от объёма
  прошлого месяца: рост объёма может снизить итоговую цену.
- **Где теряется скидка.** Фильтры по типу АЗС и региону показывают, сколько литров
  покупается у партнёров без скидки или с наценкой и в каких регионах.
- **Дорогие регионы и АЗС.** Карта в режиме «цена литра» или «скидка» подсвечивает регионы,
  где топливо дороже. Карточка АЗС сравнивает цену по договору с ценой на стеле и
  показывает, какие карты там заправляются.
- **Кто тратит.** Группы карт и топ-5 карт показывают подразделения и машины с наибольшим
  расходом. По комментарию карты видно, какая это машина.
- **Подозрительные заправки.** Блок «Контроль» находит заправки больше заданного объёма и
  серии заправок одной картой за короткое время. Пороги настраиваются.
- **Режим работы парка.** Тепловая карта по часам местного времени АЗС показывает ночные
  заправки и работу в выходные.
- **Динамика.** График за 3 месяца по любому показателю показывает тренд расхода, цен и
  скидки.
- **Нагрузка на тариф.** Блок «Запросы к API» показывает, хватит ли пакета запросов при
  выбранном расписании опроса, и подсказывает, как в него уложиться. Размер бесплатного
  пакета зависит от тарифа: проверьте его в API-портале.

## Данные прототипа

Опубликованная страница статическая: к API она не обращается, ключей в ней нет.

- **Четыре DEMO-договора.** Показатели шапки взяты из ответов DEMO API. Пригодных для
  аналитики транзакций DEMO не возвращает, поэтому они синтетические и подогнаны под литры
  и рубли договора.
- **Синтетический договор «СН-000201».** Транзакции генерируются в браузере по обезличенному
  профилю `prototype/synthetic-profile.json`. В профиле только агрегаты транзакционного
  отчёта: доли товаров, литры в чеке, цены, география. АЗС взяты из справочника API. Номер
  договора, баланс, платежи, карты, группы и условия скидок придуманы.

DEMO изолирован от рабочей среды и поддерживает не все методы, поэтому не доказывает, что
те же данные будут в рабочем договоре. Роли, видимость объектов, IP-ограничения, квоты и
тарифы задаёт сервер API.

## Как устроен рабочий дашборд

Ключи API, логин и пароль хранятся только на сервере. Сервер обращается к API через SDK по
своему расписанию, независимо от числа зрителей, и хранит историю за 3 месяца. Браузер
получает от сервера готовые снимки блоков. По умолчанию SDK ограничивает поток одним
запросом в секунду; лимит настраивается под условия договора. Подробности — в
[docs/dashboard-spec.md](docs/dashboard-spec.md).
